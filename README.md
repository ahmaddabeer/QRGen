
# 🚀 QRGen

A simple and lightweight QR Code Generator Android App built with **Kotlin** and **Jetpack Compose**.

Generate QR codes from text, save them to your Gallery, and share them with others.

## ✨ Features

- 🔲 **QR Code Generation** – Generate QR codes from text.
- 💾 **Save QR Image** – Save QR codes as PNG images in your Gallery.
- 📤 **Share QR Image** – Share QR images using Android's share menu.
- 🎨 **Modern UI** – Clean interface built with Jetpack Compose and Material 3.
